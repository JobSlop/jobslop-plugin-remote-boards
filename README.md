# Remote boards — a jobslop plugin

Remote-job boards that need no key: Himalayas, Jobicy, Remotive, RemoteOK and Arbeitnow.

## What it adds

- **Job boards:** Himalayas (Remote jobs board), Jobicy (Remote jobs board), Remotive (Remote jobs board), RemoteOK (Remote jobs board), Arbeitnow (Remote & European jobs board)
- **Its own words in:** da, es, nl

## Install

It comes with jobslop: switch it on in the welcome tour or in **Settings → Plugins**.

To get a newer version before jobslop's next release, use **Check for plugin updates**, or paste `https://github.com/JobSlop/jobslop-plugin-remote-boards` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
